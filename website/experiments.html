Hypotheses & experiments

Six testable hypotheses about crop-circle patterns, each with an explicit experiment on the bundled data (or the cited census studies) and a verdict. This is pattern-hunting on a curated dataset — verdicts describe the data, not ultimate causes.

How to reproduce

sqlite3 data/cropcircles.sqlite  ·  SELECT era, COUNT(*), AVG(size_m) FROM formations GROUP BY era;
python: pandas.read_csv('data/crop_circles.csv') → scipy.stats.spearmanr / chisquare → sklearn.cluster.KMeans

All verdicts above were computed from the shipped CSV/SQLite data in one pass; nothing is hard-coded except sourced constants (e.g., Northcote's census figures).

Skeptics' null hypothesis throughout: formations are human-made art/hoax/ads. Several supported hypotheses (seasonality, Avebury/roads, media feedback) are exactly what that null predicts.
