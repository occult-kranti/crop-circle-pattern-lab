The dataset

Four tables: formations (60 curated major formations), papers (19 research works), annual_counts (16 sourced report counts), timeline_events (6 milestones). Download as CSV or query the SQLite file directly.

crop_circles.csv papers.csv annual_counts.csv cropcircles.sqlite

Schema — formations

id, name, date (YYYY-MM-DD), date_approx (1=approximate), location, county, country, lat, lon, crop, geometry (raw), geometry_family (normalized), size_m (max dimension, metres), circles (component count), origin (reported-unexplained / confessed-hoax / circlemakers-art / commercial-commission / officially-unexplained / folklore), maker, era, significance, sources, year, month

Method & honesty notes: this is a curated set of notable formations, not a census — no authoritative global registry exists (Crop Circle Connector, CCRA and cropdecoder.com use different inclusion criteria). Sizes are approximate; Milk Hill 2001's diameter is genuinely disputed (160–300 m). Dates marked approximate where sources conflict (e.g., East Field 'DNA' 1996: 17 June vs 17 July).
