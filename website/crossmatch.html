Brute force · anti-apophenia edition

The cross-pattern similarity engine.

We brute-forced every pair across four pattern domains — 60 crop formations, 4 Klüver form constants, 8 sacred-geometry motifs, 13 monument resonators (85 items, 3,570 pairs, 139 cross-domain pairs testable) — with a weighted Gower-style distance over symmetry, vibration-mode, ratio and shape features. Then we did the part pattern-hunters skip: pre-registered an "interesting" criterion and ran 100,000 label-shuffle permutations (Westfall–Young family-wise error control).

Headline result: a clean null — and a ceiling theorem. Zero cross-domain pairs pass (FWER 0 · Bonferroni 0 · BH-FDR 0). The permutation null's minimum-distance statistic is degenerate at zero: the profile space collapses to O(10) cells shared by every ornamental tradition, so one duplicate pair (which always exists) puts an atom of mass ≈0.47 at the null's minimum and the test's power is identically zero. Read this precisely: cross-sectional motif matching is uninformative — it can neither prove nor refute cross-domain relatedness. The only substantive null is the enrichment count test (p=0.55), which rules out broad closeness. The identifiable signal is temporal (see Experiments, Round 2). — panel mathematics review

Design

Features: n-fold symmetry (octave-tolerant), topology flags (spiral/grid/concentric/chiral), decoded membrane modes (n,m) with Bessel-zero proximity (T=0.05), canonical-ratio signatures ({φ, √2, √3, 2, 3, π}, log-Gaussian σ=2%, ratio-octave folded), 32-dim rotation-invariant Fourier descriptors. Gower-style weighted composite over jointly observed features only; pairs with <3 shared feature groups excluded (1,549 of 1,688 excluded by rule — Klüver items carry no size/mode data). Pre-registration: τ=0.25, FWER α=0.05, FDR q=0.10, robust-z≥2, seed 20240601.
